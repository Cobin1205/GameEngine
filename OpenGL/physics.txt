3D PHYSICS ENGINE ARCHITECTURE OVERVIEW

I. CORE DATA STRUCTURES
- State: Position (Vector3), Orientation (Quaternion)
- Motion: Linear Velocity, Angular Velocity
- Mass: Inverse Mass (1/m), Inverse Inertia Tensor (Local and World)
- Force: Force Accumulator, Torque Accumulator
- Integration: Semi-Implicit Euler

II. COLLISION PIPELINE (THE CHAIN)
1. Broadphase: Dynamic Bounding Volume Tree (DBVT)
   - Use AABB hierarchy to prune non-colliding pairs.
2. Narrowphase Part A: GJK (Gilbert-Johnson-Keerthi)
   - Job: Determine IF objects overlap.
   - Input: Support Mapping (Vertex Data).
3. Narrowphase Part B: EPA (Expansion Polytope Algorithm)
   - Job: Find Penetration Depth and Collision Normal.
   - Trigger: Only runs if GJK returns 'true'.
4. Manifold Generation:
   - Job: Create and persist contact points over time.

III. THE SOLVER (SEQUENTIAL IMPULSES)
- Handles: Collision response, Friction, and Restitution.
- Stability: Use Warm Starting (cache previous impulses).
- Constraints: Solves velocity-level constraints iteratively.

IV. IMPLEMENTATION ROADMAP
Phase 1: Support Functions -> GJK -> EPA
Phase 2: Rigid Body Dynamics -> Quaternion Integration -> Inertia Tensors
Phase 3: Persistent Manifolds -> Sequential Impulse Solver
Phase 4: DBVT Broadphase -> Sleeping Logic -> Constraints/Joints

V. THE GOLD STANDARD TEST
- Goal: Stable Cube Stacking.
- Success: 20 cubes stacked without jitter, sinking, or rotation drift.
